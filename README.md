# 国家公務員 勤勉手当 成績率計算

行政職俸給表（一）の級・号俸、役職、勤務地、扶養親族である子の人数、勤勉手当の実際の支給額などから、勤勉手当の成績率を逆算するWeb計算ツールです。

## 公開ページの説明文

国家公務員の勤勉手当について、俸給月額や地域手当、各種加算額、期間率をもとに成績率を逆算する計算ツールです。スマートフォン・パソコンのブラウザから利用できます。

## GitHub Pagesでの公開方法

1. GitHubにログインし、`kinben-rate-calculator` という名前で新しいリポジトリを作成します。
2. リポジトリの公開設定を `Public` にします。
3. このフォルダ内の `index.html` と `README.md` をリポジトリ直下にアップロードします。
4. リポジトリの `Settings` → `Pages` を開きます。
5. `Build and deployment` の `Source` を `Deploy from a branch` にします。
6. `Branch` を `main`、フォルダを `/(root)` にして `Save` を押します。
7. 公開処理が完了すると、通常は次のURLでアクセスできます。

   `https://＜GitHubユーザー名＞.github.io/kinben-rate-calculator/`

## 更新方法

計算プログラムを修正した場合は、新しいHTMLファイルを `index.html` という名前で保存し、GitHubリポジトリ内の既存の `index.html` を置き換えてください。Pagesに自動的に反映されます（反映まで数分かかる場合があります）。

## 利用上の注意

- このツールは計算の参考として提供するものであり、国の機関が提供する公式サービスではありません。
- 計算結果の正確性・完全性を保証するものではありません。実際の支給額や成績率の確認は、所属機関の給与担当部署や適用される法令・通知等で行ってください。
- 俸給表、地域手当率、期間率、加算率、評価区分等は改正されることがあります。公開後も、適用年度・支給期に応じた内容になっているか確認してください。
- このツールは入力内容を外部サーバーへ送信・保存する仕組みを設けていません。GitHub Pagesで公開する場合、HTMLソース自体は誰でも閲覧できます。
